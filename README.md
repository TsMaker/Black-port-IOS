# Black for iOS

An unofficial native iOS port of the original Xbox version of *Black*, with touch controls, controller support, and extended graphics options.

The game's x86 code is statically recompiled ahead of time to C++ with [XboxXBE-Recomp](https://github.com/TGP482/XboxXBE-Recomp), then built for arm64. Drawing goes through Metal / Vulkan, and windowing, input, and audio through SDL3. No emulator is involved.

> [!NOTE]
> This project does not include any game assets. You must provide the files from your own legally acquired copy of the game to install or build.

## Installation (iOS)

1. Build or download the iOS `.ipa` package generated by GitHub Actions.
2. Sideload the app onto your iOS device (using tools like AltStore, TrollStore, or Sideloadly).
3. Place your legally obtained game files (`default.xbe` and data folders, or `.iso`) inside the app's document folder using the **Files** app on iOS.

## Features

The settings are in the game's own options menu, each page under its own button: **Graphics**, **Touch Controls**, **General**, **Mouse and Keyboard**, and **Cheats**. Within a page the settings are grouped under headings, and arrows above and below the list show there is more to scroll to; tap them to move the list one row.
